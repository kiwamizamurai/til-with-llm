# TIL Guidelines

This repository follows the simonw/til format. Use the `til-writing` skill for creating and managing entries.

## Naming Conventions

- Category: lowercase with hyphens (`github-actions`, `python`, `sqlite`)
- Filename: lowercase with hyphens (`using-uv-for-python.md`)

## Workflow

1. Run `/til <category> <topic>` to create a new entry
2. Run `/update-readme` after adding entries to update the index
